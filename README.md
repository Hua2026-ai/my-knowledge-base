## 文本 / 阅读（12）

### 电子书与文献

- **[Project Gutenberg](https://www.gutenberg.org)**
  - 公有领域英文电子书 7 万+ 册，EPUB / PDF 直接下载，无需注册。
- **[Internet Archive](https://archive.org)**
  - 数字图书馆，藏书 + 网页时光机 + 影音档案，找绝版资料的最后手段。
- **[维基文库](https://zh.wikisource.org)**
  - 中文公有领域文献全文库，古籍、民国书刊为主。
- **[中国哲学书电子化计划](https://ctext.org)**
  - 先秦两汉典籍原文，带逐句英译与字词索引，做古文研究很省事。
- **[书格](https://www.shuge.org)**
  - 古籍善本高清影印 PDF，审美在线，适合收藏与考据。

- **[Wayback Machine](https://web.archive.org)**
  - 网页快照归档，原文被删或改版时可以翻历史版本。

## 音视频（15）

### 视频课程

- **[中国大学 MOOC](https://www.icourse163.org)**
  - 国内高校公开课平台，名校课程免费学，部分可拿证书。
- **[Bilibili](https://www.bilibili.com)**
  - 除了娱乐，学习区和科技区有大量高质量系统课程与科普，中文首选。
- **[MIT OpenCourseWare](https://ocw.mit.edu)**
  - MIT 几乎全部课程的讲义、作业、考试题免费开放，自学硬核科目首选。
- **[Coursera](https://www.coursera.org)**
  - 国际名校与企业的体系化课程，多数可旁听（免费），证书需付费。
- **[edX](https://www.edx.org)**
  - 哈佛、MIT 等牵头的公开课平台，与 Coursera 互为补充。
- **[可汗学院（中文）](https://zh.khanacademy.org)**
  - 数学、科学基础概念讲得极清楚，适合补基础或给小孩用。

## 软件 / 工具（15）

### 开发

- **[VS Code](https://code.visualstudio.com)**
  - 主力编辑器，插件生态最全，几乎任何语言都能配成 IDE。

## 收录标准

- **能用得上**：自己真的会打开，而不是单纯看着厉害。
- **长期可用**：优先官方站点与开源项目，避开随时会挂的转载页。
- **免费优先**：能免费解决的，不花钱；收费的会特别标注。
- **合法合规**：不收录盗版影视、破解软件、侵权教材等资源。

## 怎么更新

本库的条目同时维护在 `resources.json` 里，改数据再重新生成 README 更不容易乱：

```bash
# 1. 改 resources.json，加一条 {cat, group, name, url, desc}
# 2. 重新生成并推送
python build_kb.py
```

只想临时加一条的话，直接在 GitHub 网页上编辑 `README.md` 也行，随后记得同步回 `resources.json`。
